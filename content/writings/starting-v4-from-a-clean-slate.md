This is the fourth version of this site. Instead of patching the old one, I started from an empty Hugo project and only added what I needed.

The goals were short: fast pages, light weight, a minimal style and as little JavaScript as possible. When Hugo already does something, I use Hugo's built-in feature instead of adding a tool.

Each piece came in as its own small change: the skeleton, deployment, Writings, Topics, prose features, standard pages, search and finally the visual design.
